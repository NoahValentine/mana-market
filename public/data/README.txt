Mana Market data pack
=====================

The four files here (meta.json, cards.json, series.bin, trends.json) are built
by `npm run pack` and are what the app reads for the Market and Trends views.

The copy committed to git is a DEMO pack: real card names with synthetic prices
and a synthetic 90-day history, generated by `node test/make-demo-pack.mjs`. It
exists so a fresh clone and a first deploy have something to render.

The first real run replaces all four files:

  npm run ingest      # today's snapshot from Scryfall bulk data -> history/<day>.csv
  npm run pack        # history/*.csv -> the four files here

After that the nightly GitHub Action rebuilds them every day and uploads them
with `wrangler deploy`; it deliberately does not commit them back to git.
